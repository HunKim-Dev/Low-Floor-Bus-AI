# Low-Floor Bus AI

> 사용자의 준비 시간과 이동 속도를 고려해, 탈 수 있는 저상버스와 출발 시각을 알려주는 AI 이동 도우미

Low-Floor Bus AI는 휠체어 사용자, 시각장애인 등 교통약자가 저상버스를 놓치지 않도록 돕는 **모바일 우선 웹앱(PWA) 프로토타입**입니다.

단순히 버스 도착 시간만 보여주는 대신 다음 정보를 함께 계산합니다.

- 사용자의 외출 준비 시간
- 출발지에서 승차 정류장까지의 이동 시간
- 신호 대기와 돌발 상황을 위한 안전 여유 시간
- 저상버스의 예상 도착 시각

계산 결과를 바탕으로 여유 있게 탑승 가능한 차량을 고르고, **언제 준비하고 언제 출발해야 하는지** 큰 글씨와 음성·진동·브라우저 알림으로 안내하는 것이 핵심입니다.

## 현재 구현 상태

이 저장소는 해커톤 제출을 위해 개발 중인 프로토타입입니다. Vercel에 웹 형태로 배포할 수 있으며 APK나 데스크톱 설치 파일은 사용하지 않습니다.

| 기능 | 상태 | 설명 |
| --- | --- | --- |
| 모바일 우선 반응형 UI | 구현 완료 | 큰 터치 영역과 단순한 핵심 동선 제공 |
| PWA 설치 | 구현 완료 | 모바일 브라우저에서 홈 화면에 추가 가능 |
| 개인별 출발 시각 계산 | 구현 완료 | 준비·이동·여유 시간을 저상버스 ETA와 대조 |
| 이동 속도 반영 | 구현 완료 | 경로 도보 시간에 개인 배율 적용 또는 직접 입력 |
| 출발지·도착지 입력 | 구현 완료 | 장소 검색, 현재 위치, 음성 및 텍스트 수정 지원 |
| 음성 받아쓰기 | 연동 코드 완료 | Cloudflare Whisper 녹음 전송, 최대 15초. 키가 없으면 기기 음성인식 |
| 음성 문장 해석 | 연동 코드 완료 | Cloudflare Qwen으로 경로·시간 변경·출발 질문 해석, 실패 시 기본 해석 |
| 장소 검색 | 연동 코드 완료 | 실제 지도 서비스 자격증명과 운영 검증 필요 |
| 대중교통 경로 | 연동 코드 완료 | 환승 없는 버스 경로를 최대 3개 사용 |
| 주변 정류장·도착정보 | 연동 코드 완료 | 공공데이터 자격증명과 지원 데이터 필요 |
| 음성 안내 | 연동 코드 완료 | 모든 안내에 Gemini 2.5 Flash TTS 사용. 실패 시 화면 안내·재시도, 다른 음성으로 전환하지 않음 |
| 진동 알림 | 구현 완료 | 지원 기기의 진동 API 사용 |
| 백그라운드 예약 푸시 | 미구현 | 현재는 페이지가 실행 중일 때만 안정적으로 알림 |

저장소에는 실제 외부 서비스 비밀키가 포함되어 있지 않습니다. 별도 연결 없이 실행하면 명시적인 체험 경로만 예시 데이터로 보여주며, 실제 조회 실패를 체험 데이터로 조용히 대체하지 않습니다.

## 주요 사용자 흐름

1. 출발지를 검색하거나 **현재 위치에서 출발**을 선택합니다.
2. 도착지를 검색하거나 음성으로 출발지와 도착지를 함께 말합니다.
3. 실제 경로에서 승차 정류장, 하차 정류장과 직행 버스 노선을 찾습니다.
4. 서버에서 해당 노선의 실시간 도착정보를 확인하고, 저상버스만 앱에 전달합니다.
5. 준비 시간 + 개인화된 정류장 이동 시간 + 안전 여유 시간을 계산합니다.
6. 지금부터 여유 있게 탈 수 있는 가장 가까운 저상버스를 추천합니다.
7. 준비 시작 시각과 출발 시각을 화면·음성·진동으로 안내합니다.

예시 음성:

```text
현재 위치에서 서울역까지
연세대학교에서 홍대입구역까지
준비 시간 5분으로 바꿔줘
현재 위치에서 서울역까지, 준비는 5분
몇 분 뒤에 나가면 돼?
두 번째 장소
```

음성 인식 결과가 틀리면 **글로 입력**을 눌러 문장을 수정할 수 있습니다. 이름이 같거나 일부만 일치하는 장소는 앱이 임의로 확정하지 않고 주소를 보여준 뒤 사용자가 선택하도록 합니다.

### 타는 정류장 찾기

- 정류장 이름·공개 정류장 번호·버스 방향·해당 버스의 다음 정류장을 화면과 Gemini 음성으로 안내합니다. 도착정보가 없어도 확인된 경로 정보는 유지하고, 저상 차량이나 출발 시각은 확정하지 않습니다.
- 정류장 번호(`nodeno`)와 다음 정류장은 순서·방향·좌표가 일치한 TAGO 노선에서 가져옵니다. 내부 ID(`nodeid`)나 노선 순번(`nodeord`)을 정류장 번호로 표시하지 않습니다. 번호가 없으면 생략하며 음성에서는 숫자를 한 자리씩 읽습니다.
- 좌표가 있으면 **지도에서 타는 곳 보기**로 승차 위치를 엽니다. [카카오 지도 공식 링크 형식](https://apis.map.kakao.com/web/guide/#bigmapurl)을 사용합니다.
- **주변에 물어볼 때**를 펼치면 정류장·노선·방향을 담은 질문을 크게 보여주거나 Gemini로 읽어줄 수 있습니다. 다른 사람에게 자동 전송하지 않습니다.
- 현재 보행 구간의 좌우 방향·횡단보도·휠체어 접근 가능 여부는 검증하지 못합니다. 확인되지 않은 길 안내를 만들지 않으며, 반대편 정류장과 혼동하지 않도록 현장에서 번호와 방향을 확인해야 합니다.

## 추천 계산 방식

```text
필요 시간 = 준비 시간 + 정류장 이동 시간 + 안전 여유 시간
```

예를 들어 준비 3분, 정류장 이동 7분, 여유 2분이면 최소 12분이 필요합니다. 5분 뒤 오는 저상버스는 제외하고 18분 뒤 오는 저상버스를 추천합니다.

버스의 최초 조회 시각과 초 단위 ETA를 절대 도착 시각으로 저장하기 때문에, 화면에서 시간이 지나도 출발 예정 시각이 뒤로 밀리지 않습니다. 도착정보가 오래되거나 추천 차량의 시각이 크게 바뀌면 기존 알림을 중지하고 재확인을 요청합니다.

## 데이터 및 AI 처리 흐름

```text
사용자 음성
  → 최대 15초 녹음 → Cloudflare Whisper 받아쓰기 (미연결 시 기기 음성인식)
  → Cloudflare Qwen으로 경로·시간 설정·출발 질문 추출 (미연결 시 기본 해석)
  → 지도 장소 검색으로 실제 좌표 확인
  → 대중교통 경로 조회
  → 정류장·실시간 도착정보 연결
  → 저상버스 필터링 및 개인별 출발 시각 계산
  → 화면·음성·진동 알림
```

읽어주는 음성은 Gemini 2.5 Flash Preview TTS를 사용합니다. Cloudflare와 별도로 Google AI Studio의 서버 전용 키를 사용하며,
도착정보 없음·오류 안내까지 같은 Gemini 목소리를 사용합니다. 키가 없거나 한도 초과·합성 실패가 발생하면 화면에 오류를 표시하며 다른 목소리로 전환하지 않습니다. 기본 목소리는 Sulafat이며 설정에서 속도를 조절하고 미리 듣거나 멈출 수 있습니다. 이전에 저장한 기기 음성 선택은 더 이상 적용하지 않습니다.
마이크를 켜면 재생·생성 대기를 취소합니다. 출발 알림용 Gemini 오디오는 미리 생성합니다. 알림 시각에 준비되지 않았으면 화면·알림·진동을 유지하고 안내 듣기로 다시 확인하게 합니다. 늦게 생성된 출발 명령을 뒤늦게 재생하지 않습니다.
한국어 오디오 생성은 실제 계정으로 확인했습니다. 발음·자연스러움과 모바일 실기기별 재생 품질은 별도 청취 검증이 필요합니다.

### 음성 문장 해석

- 외부 AI가 꺼져 있으면 기기 음성인식과 로컬 규칙 기반 해석을 사용합니다.
- Cloudflare가 연결되면 마이크 녹음을 16kHz 모노 WAV로 변환해 Whisper로 전송합니다. 손을 떼거나 15초가 되면 한 번 전송합니다.
- 언어 모델(Qwen)에는 이번에 인식된 텍스트와 현재 확인 중인 입력 항목만 전달합니다.
- GPS 좌표와 장소 후보 목록은 언어 모델에 전달하지 않습니다. 오디오는 Whisper에만 전달합니다.
- 언어 모델은 경로 검색어, 명시적으로 말한 시간 변경, 출발 시간 질문 여부, 확인 질문만 반환합니다.
- 주소, 좌표와 장소 ID는 모델이 생성하지 않고 지도 검색 결과로만 확정합니다.
- 모델 오류나 시간 초과가 발생하면 로컬 해석으로 전환하고 현재 모드를 화면에 표시합니다.
- 준비·출발 시각은 AI가 생성하지 않고 기존 계산 코드가 최신 도착정보로 결정합니다.
- 장소를 다시 선택하는 과정에서도 함께 말한 준비·이동·여유 시간을 유지합니다.
- 실제 사용자 발화와 모바일 기기별 품질 검증은 아직 필요합니다. 연결 규격과 검증 절차는 [AI 연결 가이드](docs/ai-integration.md)에 정리했습니다.

### 장소·경로·도착정보

- 장소 검색 결과가 없으면 띄어쓰기 보정과 주소 검색을 시도합니다.
- 부분 일치 결과가 하나뿐이어도 사용자가 주소를 확인하기 전에는 자동 확정하지 않습니다.
- 현재 버전은 **환승 없는 단일 버스 경로**를 최대 3개 사용합니다.
- 사용자는 다른 직행 버스 경로를 선택할 수 있습니다.
- TAGO **버스정류소정보·버스노선정보·버스도착정보** 3개 API의 활용 승인이 필요하며, 기존 `TAGO_BUS_API_KEY` 하나를 공통으로 사용합니다.
- 승차 위치 주변 도시의 동일 번호 노선을 조회하고, 해당 노선의 **경유 정류장 순서·진행 방향·승하차 좌표**를 지도 경로와 비교합니다.
- 확인된 정류소 ID·도시코드·노선 ID로 도착정보를 조회해, 반대편 정류장이나 같은 번호의 다른 노선을 제외합니다.
- [TAGO 버스도착정보 API](https://www.data.go.kr/data/15098530/openapi.do)는 차량유형 요청 필터를 제공하지 않습니다. 서버에서 모든 응답 페이지를 조회한 뒤 `vehicletp`가 `저상버스`인 차량만 `/api/buses`로 반환합니다(공백 무시). 일반·비저상·유형 미확인 차량은 제외하고, 저상 차량이 없으면 빈 목록을 반환합니다. 화면 추천 단계에서도 저상 여부를 다시 확인합니다.
- 정류장 순서가 불일치하거나 후보가 여러 개면 임의로 연결하지 않습니다. 이때 경로는 표시하지만 실시간 출발 추천은 제공하지 않습니다.

## 로컬 실행

### 요구 환경

- Node.js 22.13 이상
- npm

### 설치 및 실행

```bash
git clone https://github.com/HunKim-Dev/Low-Floor-Bus-AI.git
cd Low-Floor-Bus-AI
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다. 포트를 직접 지정하려면 다음과 같이 실행합니다.

```bash
npm run dev -- --port 3001
```

## Vercel 배포

1. Vercel에서 이 GitHub 저장소를 가져옵니다.
2. Framework Preset은 Next.js를 선택합니다.
3. Build Command는 기본값인 `npm run build`를 사용합니다.
4. 배포 후 공개 HTTPS 주소에서 위치·마이크·알림 권한을 확인합니다.

이 프로젝트는 웹 서비스이므로 해커톤에는 Vercel의 공개 URL을 제출하면 됩니다. 심사 기간에는 로그인 없이 접근할 수 있고 계속 공개된 상태를 유지해야 합니다.

## API 라우트

| 경로 | 역할 |
| --- | --- |
| `GET /api/places` | 장소명·주소 검색 |
| `GET /api/routes` | 출발지와 도착지 사이의 직행 버스 경로 조회 |
| `GET /api/stops` | 현재 좌표 주변 정류장 조회 |
| `GET /api/buses` | 선택 정류장과 노선의 저상버스 실시간 도착정보만 조회 |
| `POST /api/transcribe` | 최대 15초 WAV를 Whisper로 받아쓰기 |
| `POST /api/voice-intent` | 경로·시간 변경·출발 질문을 검증된 명령으로 추출 |
| `POST /api/tts` | 최대 600자 안내 문장을 Gemini TTS WAV 오디오로 변환 |
| `POST /api/assistant` | 이전 규칙 기반 호환 API (현재 음성 화면에서는 호출하지 않음) |

## 위치·음성·알림 권한

- 현재 위치는 HTTPS 또는 localhost 같은 보안 컨텍스트에서만 사용할 수 있습니다.
- 기기와 브라우저의 위치 권한을 모두 허용해야 합니다.
- 일부 앱 내장 브라우저에서는 권한이 허용돼도 위치 조회가 시간 초과될 수 있습니다. 실제 배포 검증에는 최신 Chrome 또는 Safari를 권장합니다.
- 위치 조회는 정밀 모드가 실패하면 일반 모드로 한 번 더 시도합니다.
- Web Speech Recognition 지원 여부와 정확도는 브라우저 및 운영체제에 따라 다릅니다.
- Cloudflare 받아쓰기는 MediaRecorder와 Web Audio API를 지원하는 HTTPS 환경이 필요합니다. 실패 시 글로 입력하거나 기기 음성인식으로 전환할 수 있습니다.
- 읽어주는 목소리는 Gemini 합성 음성만 사용합니다. 네트워크·할당량·브라우저 재생 권한에 따라 음성이 나오지 않을 수 있으며, 화면 안내와 다시 듣기를 제공합니다.
- 진동은 지원되는 모바일 브라우저에서만 동작합니다.

## 체험 모드

외부 데이터 연결 전에도 첫 화면의 **체험 경로로 둘러보기**에서 다음 흐름을 확인할 수 있습니다.

- 예시 출발지·도착지
- 직행 버스 경로
- 저상버스만 포함한 예시 도착정보
- 준비·이동·여유 시간 계산
- 탑승 가능한 저상버스 추천
- 도착시간 변동 시연
- 음성 안내와 화면 내 출발 알림

체험 정보에는 명시적으로 예시임을 표시합니다. 임의의 실제 위치나 사용자가 검색한 장소에 예시 버스를 결합하지 않습니다.

## 검증

```bash
npm test
npm run build
npm run lint
```

현재 자동 테스트는 다음을 포함합니다.

- 초 단위 ETA와 시간 경과 계산
- 탑승 불가능한 버스 제외
- 준비·출발 알림 중복 방지
- 설정 저장값 검증
- 이동 속도 배율과 직접 입력
- 한국어 음성 경로 해석과 후속 입력
- 동명이인 장소 선택과 입력 유지
- 장소 검색 재시도와 외부 응답 검증
- AI 구조화 응답 검증과 장애 시 로컬 전환
- Cloudflare 인증 헤더·모델 요청·응답 계약, 키 미등록 시 외부 호출 방지
- 최대 15초 녹음, 권한 대기 중 손 떼기, 취소 시 마이크 종료
- WAV 실제 길이·형식·무음 검증, API 크기·출처·오류 처리
- 모의 Whisper → Qwen → 장소 확인 → 출발 시각 계산 연결 테스트
- Gemini 인증·한국어 요청·PCM/WAV 변환, 크기·형식 검사, 재생 취소·캐시·자동 재생 차단·기기 음성 전환 방지
- 위치 권한 오류, 정밀 위치 재시도, 취소 및 좌표 검증

프로덕션 빌드와 핵심 수정 파일 정적 검사는 통과했습니다. 전체 `npm run lint`에는 현재 사용하지 않는 일부 공용 UI 컴포넌트의 기존 검사 오류가 남아 있습니다.

추가 Chrome 검사에서는 모바일 크기 화면의 녹음→WAV→모의 AI 응답→출발 안내, 버튼 위치 유지, 15초 종료 및 취소·오류 복구를 확인했습니다.
선택 실행 스크립트는 `tests/voice-ui.smoke.mjs`와 `tests/tts-ui.smoke.mjs`이며 Playwright와 Chrome이 필요합니다. 실제 한국어 발화·합성 품질 테스트와는 구분합니다.

## 알려진 제한

- 실제 외부 서비스 자격증명과 운영 데이터는 배포 환경에서 별도로 검증해야 합니다.
- 대중교통 경로와 공공 정류장 데이터 사이에 공식 공통 식별자가 없어 정류장명과 거리로 보수적으로 연결합니다.
- 버스 운행 방향은 TAGO 노선의 정류장 순서로 검증합니다. 지원되지 않는 지역이나 지도·공공데이터가 일치하지 않는 구간은 실시간 도착정보 연결이 제한됩니다.
- 여러 번 환승하는 경로와 지하철 혼합 경로는 지원하지 않습니다.
- 모든 경로 후보의 저상버스 ETA를 동시에 비교하는 전역 최적화는 아직 없습니다.
- 휠체어 경사로, 엘리베이터, 보도 경사와 턱 등 보행 접근성 정보는 아직 반영하지 않습니다.
- 앱을 닫거나 화면이 잠긴 상태에서도 동작하는 서버 기반 예약 푸시는 구현되지 않았습니다.
- Gemini 한국어 생성은 실제 계정으로 확인했으나, 발음·자연스러움과 Android/iOS 실기기별 품질은 별도 검증이 필요합니다. Gemini 오류 시 다른 목소리로 대체하지 않으므로 음성 없이 화면 안내만 제공될 수 있습니다.
- 현재 위치는 앱 내장 브라우저보다 실제 Chrome·Safari에서 검증하는 것이 안전합니다.

## 보안과 개인정보

- 모든 외부 서비스 비밀키는 서버에서만 사용합니다.
- 음성 텍스트 입력은 300자로 제한합니다.
- AI 응답은 구조화된 스키마와 추가 런타임 검증을 모두 통과해야 사용합니다.
- 앱 자체는 음성 오디오와 대화 기록을 저장하지 않습니다.
- Cloudflare 사용 시 녹음은 받아쓰기 서비스로, 텍스트는 언어 모델로 전송합니다. 기기 음성인식도 브라우저 제공자의 처리를 거칠 수 있습니다.
- Gemini 음성을 사용하면 읽을 안내 문장을 Google에 전송합니다. 무료 등급은 입력·출력을 제품 개선에 사용할 수 있으므로 민감한 내용을 입력하지 마세요. 운영자가 `VOICE_TTS_ENABLED=false`로 설정하면 TTS 호출을 중지합니다.
- AI API에는 인스턴스별 요청 제한이 있습니다. 운영 규모의 남용 방지는 배포 방화벽 또는 공유 저장소 기반 제한이 별도로 필요합니다.
- 위치 좌표는 경로·주변 정류장 조회에 사용하며 현재 구현에서는 별도 데이터베이스에 저장하지 않습니다.
- 외부 API 오류 시 실제 데이터처럼 보이는 예시 값을 자동으로 표시하지 않습니다.
