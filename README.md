# 버스마중 AI

사용자의 준비시간, 정류장까지 이동시간, 안전 여유시간을 반영해 탑승 가능한 저상버스와 출발 시각을 추천하는 모바일 우선 PWA입니다.

## 로컬 실행

```bash
npm install
npm run dev
```

프로덕션 확인은 `npm run build`로 실행합니다.

## Vercel 배포

이 폴더를 Git 저장소로 올린 뒤 Vercel에서 저장소를 가져오면 Next.js 프로젝트로 자동 인식됩니다. Build Command는 기본값인 `npm run build`를 사용합니다.

Vercel의 Project Settings → Environment Variables에 다음 값을 등록합니다.

- `TAGO_BUS_API_KEY`: 공공데이터포털에서 버스도착정보와 버스정류소정보 활용신청 후 받은 일반 인증키
- `TAGO_CITY_CODE`: 위치를 사용하지 않을 때 기본 도착정보 조회에 쓸 도시코드(선택)
- `TAGO_NODE_ID`: 위치를 사용하지 않을 때 기본으로 조회할 정류소 ID(선택)

키가 없거나 외부 API가 응답하지 않으면 앱은 자동으로 시연 데이터 모드로 전환됩니다.

## 주요 기능

- 현재 위치 반경 500m 정류장 조회 및 거리순 정렬
- 정류장 이름·버스 번호 검색
- 저상버스 도착정보와 개인 이동시간을 결합한 출발 추천
- 음성·진동·브라우저 알림
- 홈 화면 설치 가능한 PWA
- AI 요청 분석 과정과 추천 근거 표시

현재 AI 요청 해석은 외부 모델 키 없이 실행되는 로컬 에이전트 계약으로 구현되어 있습니다. 실제 모델을 연결할 때는 `/api/assistant`의 입력·출력 형식을 유지하면 화면 코드를 바꾸지 않고 교체할 수 있습니다.
