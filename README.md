# Low-Floor Bus AI

사용자의 준비시간, 정류장까지 이동시간, 안전 여유시간을 반영해 탑승 가능한 저상버스와 출발 시각을 추천하는 모바일 우선 PWA입니다.

## 로컬 실행

```bash
npm install
npm run dev
```

프로덕션 확인은 `npm run build`로 실행합니다.

## Vercel 배포

이 폴더를 Git 저장소로 올린 뒤 Vercel에서 저장소를 가져오면 Next.js 프로젝트로 자동 인식됩니다. Build Command는 기본값인 `npm run build`를 사용합니다.

Vercel의 Project Settings → Environment Variables에 다음 값을 등록합니다.

- `KAKAO_REST_API_KEY`: 카카오디벨로퍼스 앱의 REST API 키. 장소 검색과 출발지·도착지 대중교통 경로 조회에 사용
- `TAGO_BUS_API_KEY`: 공공데이터포털에서 버스도착정보와 버스정류소정보 활용신청 후 받은 일반 인증키
- `TAGO_CITY_CODE`: 위치를 사용하지 않을 때 기본 도착정보 조회에 쓸 도시코드(선택)
- `TAGO_NODE_ID`: 위치를 사용하지 않을 때 기본으로 조회할 정류소 ID(선택)

첫 화면에서 출발지·도착지를 선택합니다. 키가 없을 때는 `체험 경로로 둘러보기`로 기능을 확인할 수 있습니다. 현재 GPS 위치나 임의의 출발지에 신촌 예시 경로를 붙이지 않습니다. 실제 조회 실패 시 예시 데이터로 대체하지 않습니다.

`KAKAO_REST_API_KEY`는 서버에서만 읽으며 브라우저로 전달하지 않습니다. 카카오디벨로퍼스에서 카카오맵 API 사용 설정을 확인한 뒤 등록하세요.

## 출발지·도착지 경로 흐름

1. `/api/places?query=...`가 카카오 장소 검색 결과를 좌표와 함께 반환합니다.
2. `/api/routes`가 출발지와 도착지 좌표로 대중교통 경로를 조회합니다.
3. 환승 없는 버스 경로를 최대 3개 반환하고 실시간 도착정보 연결이 가능한 경로를 우선 표시합니다. `다른 버스 경로 보기`에서 대안을 선택할 수 있습니다. 전체 후보의 저상버스 ETA를 비교하는 자동 경로 최적화는 아직 제공하지 않습니다.
4. TAGO 키가 있으면 승차 구간 시작 좌표 주변에서 이름이 정확히 일치하는 정류장을 찾아 실시간 저상버스 도착정보 조회용 ID와 연결합니다.

카카오 경로에는 TAGO 정류소 ID가 포함되지 않습니다. 따라서 같은 이름의 정류장이 가까이 붙어 있어 방향을 확정하기 어려운 경우에는 잘못된 도착정보를 보여주지 않도록 자동 연결을 생략합니다. 이때 경로는 계속 안내하지만 실시간 도착정보 가능 여부(`arrivalLookupAvailable`)는 `false`입니다.

경로 API는 다음 쿼리 값을 받습니다.

```text
/api/routes?originLat=37.56001&originLng=126.93686&originName=연세대학교 정문&destinationLat=37.5569&destinationLng=126.92375&destinationName=홍대입구역
```

## 현재 동작과 제한

- 도착 예정 시각을 기준으로 남은 시간을 계산합니다. 실시간 도착정보는 화면이 보일 때 30초마다 갱신하며, 화면 복귀·네트워크 복구 시에도 다시 조회합니다.
- 알림은 절대 시각에 예약됩니다. 목소리·음성 속도 변경으로 예약 시각이 밀리지 않으며, 이동 시간 변경 시 새 추천으로 다시 켜도록 안내합니다.
- 현재 알림은 **페이지가 실행 중일 때의 알림**입니다. 모바일 표시에는 서비스 워커 `showNotification`을 사용하지만, 앱 종료·화면 잠금 상태에서의 예약 푸시는 구현되지 않았습니다. PWA 설치만으로 이 제한이 해결되지는 않습니다.
- 경로의 도보 예상 시간에 개인 배율(1배/1.5배/2배)을 적용하거나, 이동 시간을 직접 지정할 수 있습니다. 실제 이동속도 학습, 계단·경사로·휠체어 진입 가능 여부는 반영하지 않습니다.
- 읽어주는 음성은 기기의 Web Speech 합성 음성입니다. 외부 고품질 TTS는 연결되지 않았습니다. 문장 해석 LLM은 아래 환경변수로 선택적으로 연결합니다. 자동 알림을 꺼도 `안내 듣기`와 `미리 듣기`는 사용할 수 있습니다.
- 길게 눌러 말하기(최대 15초), 한 번 눌러 시작·종료하는 대체 조작, 숫자·한국어 수사 시간 설정을 지원합니다.
- 정류장 이름이 같은 후보가 승차 좌표 120m 내에 여러 개면 자동 연결을 생략합니다. 실제 운행 방향을 노선 정류장 순서로 검증하는 기능은 추가 연동이 필요합니다.

## 검증

`npm test`는 시간 경과, 초 단위 도착시간, 알림 중복·지연, 설정 검증, 이동속도 반영, 음성 문장 해석을 확인합니다.
`npm run build`로 프로덕션 빌드와 타입을 확인합니다.

## 주요 기능

- 현재 위치 또는 검색한 장소를 출발지로 설정
- 출발지·도착지 장소 검색 및 올바른 방향의 직행 버스 경로 선택
- 저상버스 도착정보와 개인 이동시간을 결합한 출발 추천
- 음성·진동·브라우저 알림
- 홈 화면 설치 가능한 PWA
- 음성 요청 해석과 추천 근거 표시

## 음성 문장 해석과 장소 검색

- 브라우저 음성 인식 → `/api/voice-intent`에서 출발·도착 검색어 추출 → `/api/places`에서 실제 장소 확인 → `/api/assistant`에서 검증된 장소 ID와 시간 설정 적용 순서입니다.
- `VOICE_AI_ENABLED=true`, `OPENAI_API_KEY`를 **서버 환경변수**에 설정하면 OpenAI Responses API로 문장을 해석합니다. 기본 모델은 `gpt-4.1-mini`이며 `OPENAI_VOICE_INTENT_MODEL`로 Structured Outputs 지원 모델을 지정할 수 있습니다.
- 기본값은 외부 AI 비활성화입니다. 키가 없거나 모델 요청이 실패하면 기본 규칙 해석으로 전환하고 화면에 구분해서 표시합니다. AI가 실제로 호출되지 않았는데 호출했다고 표시하지 않습니다.
- AI에는 이번에 말한 글(최대 300자)과 현재 확인 중인 항목만 보냅니다. 오디오·GPS 좌표·장소 후보 목록은 보내지 않으며 `store:false`를 사용합니다. 이것이 공급자의 모든 로그·보관 정책을 없앤다는 의미는 아닙니다. 앱 자체에는 음성 대화 기록을 저장하지 않습니다.
- 모델은 검색어와 확인 질문만 반환할 수 있습니다. 주소/좌표/장소 ID는 모델 응답에서 허용하지 않습니다. 실제 장소는 지도 검색 결과로 결정합니다.
- 같은 이름이 여러 개이거나 일부만 일치하는 결과는 주소를 보고 선택합니다. 한 개뿐인 부분 일치 결과도 임의로 확정하지 않습니다.
- 확인한 장소와 아직 확인하지 않은 검색어는 임시로 유지합니다. “도착지만 다시 말하기”, 후보에서 “2번”, “두 번째”로 선택하기, `글로 입력`에서 인식 문장 수정하기를 지원합니다. 닫기를 누르거나 수동 장소 선택을 새로 열면 임시 흐름을 취소합니다.
- 장소 검색은 띄어쓰기를 제거한 재검색과 주소 검색을 지원합니다. 잘못 들린 지명을 비슷한 다른 지명으로 임의 변환하지 않습니다.
- 실제 장소 검색 미설정, 검색 결과 없음, 공급자 연결 실패를 구분합니다. 실제 조회 실패를 체험 결과로 덮지 않습니다.

### 연결에 필요한 사용자 설정

1. 카카오 REST API 키를 `.env.local` 또는 Vercel 서버 환경변수의 `KAKAO_REST_API_KEY`에 등록합니다. 카카오 앱의 API 사용 권한도 확인해야 합니다.
2. OpenAI API 키를 `OPENAI_API_KEY`에 등록하고 `VOICE_AI_ENABLED=true`로 설정합니다. 별도 API 과금과 해당 모델 사용 권한이 필요합니다.
3. 로컬 서버를 재시작하거나 Vercel에서 다시 배포합니다. 키를 채팅·Git·`NEXT_PUBLIC_*` 변수에 넣지 마세요.
4. 실제 한국어 발화로 장소·동명이인 후보·위치 권한 거부를 검증합니다. 테스트의 모의 모델 응답 통과는 실제 모델의 인식 정확도를 보장하지 않습니다.

`/api/voice-intent`에는 요청 크기 제한, 8초 모델 타임아웃, 출력 구조 검증, 다른 웹사이트 요청 차단, 인스턴스당 분당 30회 제한을 넣었습니다. 이 메모리 제한은 분산 배포 전체의 한도가 아닙니다. 공개 배포 전에는 공급자 사용량 제한과 별도의 인증/분산 호출 제한을 적용해야 합니다.

음성 받아쓰기 엔진과 읽어주는 목소리는 이번 연결과 별개입니다. 실제 모바일 마이크 인식률, 공급자 실호출, 교통 API 권한, 실시간 저상버스 연결은 키 등록 후 검증해야 합니다.

구현 기준: [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [카카오 장소·주소 검색](https://developers.kakao.com/docs/ko/local/dev-guide).
