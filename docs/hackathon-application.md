# 해커톤 신청서 초안

## 제목

버스마중 — 내 속도에 맞춘 저상버스 AI 이동 도우미

## 해결하고자 한 문제

휠체어 사용자와 시각장애인이 저상버스를 이용할 때, 자신의 준비시간과 이동속도에 맞춰 언제 출발해야 하는지 알기 어렵습니다.

## AI 활용 방식 및 결과

Whisper로 한국어 음성을 텍스트로 변환하고, Qwen으로 출발지·도착지와 시간 설정을 해석하도록 구현했습니다. 카카오 API로 장소와 직행 버스 경로를 조회하고, TAGO에서 저상버스로 확인된 도착정보만 선별합니다. 도착정보가 제공되는 노선에서는 준비·이동·여유 시간을 반영해 탈 수 있는 차량과 출발 시각을 계산합니다. Gemini TTS를 연동해 정류장·방향·출발 안내를 음성으로 읽어주도록 구현했습니다. AI는 음성 인식·문장 해석·음성 합성에 사용하고, 출발 시각은 실제 도착정보와 계산 코드로 결정합니다.

## 사용 AI툴 및 기술 스택

신청서 선택 항목: Next.js, React, ChatGPT, Gemini, Whisper

Vercel 배포를 완료하면 Vercel도 선택합니다.

기타 입력란이 있다면: Codex, Cloudflare Workers AI, Qwen3-30B-A3B, TypeScript, Tailwind CSS, 카카오 API, 공공데이터포털 TAGO API, PWA

---

작성 기준: 현재 구현된 모바일 웹 프로토타입. 실제 이용자 실증 수치, 모든 경로 후보의 저상버스 도착시간 자동 비교, 휠체어 접근 경로 검증은 성과에 포함하지 않았습니다. 문제 설명은 공백 포함 100자 이내, AI 활용 방식 및 결과는 500자 이내입니다. Gemini TTS는 연동·음성 생성 확인 이력이 있으며, 현재 무료 한도 소진 상태이므로 사용자가 API 결제를 연결한 뒤 재생을 다시 확인해야 합니다.
